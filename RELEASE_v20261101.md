## Change — Plans in 4 stages
My learning › Plans now walks through four separate stages, shown in the stepper at the top:
1. **Select a profession** — the list from the user's path (+ saved plans).
2. **Profession overview** — A (what it is, pros/cons, trends) and B (future, demand, AI & robots, career/salary),
   ending with **"Next: select the skills to learn →"**. No skill list on this page any more.
3. **Select skills** — the top 10 skills (difficulty + "Learn it" videos), tick 1–10, plan length
   (recommendation 1–2 → 30 days, 3–5 → 3 months, 6–10 → 1 year, still changeable) and the 3 quick questions → Create.
4. **Your study plan** — unchanged content; Save as HTML / Print / PDF; "Change skills or length" returns to stage 3.

- Any stage already reached is clickable in the stepper (e.g. back to the overview, then on to skills — the
  selection is kept). "← Back to the overview" on stage 3, "← Other profession" on stage 2.
- Opening a saved plan lands on stage 4 with its skills pre-ticked if you go back to stage 3.
- Fix: the plan length now resets when a new profession is opened (the reset had been commented out by mistake).
- Texts EN / FR / ES: step1–step4, nextSkills, backOverview, skillsOf. No backend or database change.
